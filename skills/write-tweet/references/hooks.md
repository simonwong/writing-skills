# 开头

入口可以从正文里提一句到最前，也可以另写。

## 判断标准

- 读到第一行，读者知道这条在说什么，或知道接下来要看什么。
- 第一行的承诺正文兑现：说了结果就交代怎么来的，预告了几点就给几点。
- 有助于理解、语气或节奏的铺垫保留；空转、夸大或制造正文不兑现的悬念的删。
- 结合配图、视频或被引用的推文读第一行。

## 入口

| 入口 | 示例 |
| --- | --- |
| 结果或数字前置 | 三个月没点外卖，每月伙食费从两千降到九百。 |
| 直接判断 | 租房先看采光，家具可以以后再添。 |
| 自己遇到的问题 | 新买的扫地机每天都卡在厨房门槛上。 |
| 反应加事件 | 有点意外。楼下面包店把排队号码做成了小程序，能看到前面还有几个人。 |
| 原文里最反直觉的一句 | 书里说，每天只读十页的人，一年读完的书反而最多。 |
| 正在做的事 | 这周在把阳台改成小菜园，先种了三盆葱。 |
| 反差（两端都是具体事） | 换了更贵的跑鞋膝盖还是疼，把步幅缩小一点就好了。 |
| 作品或现象 | 女儿画的全家福里，只有猫是彩色的。 |
| 疑问 | 同样的面粉和水，为什么家里烙的饼总比店里的硬？ |

## 容易空转的开头

这些第一行换任何内容都能套：先表态再说事（「不受欢迎的观点：」「有一说一」）、禁令和讣告（「别再 X 了」「X 已死」）、数字接悬念（「我用 N 天做到 X，但真正起作用的只有一个」）、破折号留白、收藏引导、接不上具体事的感叹（「太离谱了」）。遇到时看正文是否兑现，兑现不了的换成直接给实质信息。
