# WeChat Cover

微信公众号文章封面：横版和方版两种尺寸，默认拼成一张双版母版。

## 文案

- 主文案优先 4–12 个汉字，中英文混排按实际字宽判断。
- 辅助关键词 1–2 个。
- 同一文章的横版与方版用同一组文字和同一组颜色。

## 提示词开头

```text
Use case: ads-marketing
Asset type: 微信公众号文章封面

制作可直接用于文章封面的平面图片，不是展示海报或设备样机。
```

## 布局

默认用双版母版；用户只要单版或指定其他尺寸时遵循请求。以下尺寸是本 playbook 的设计规格，不宣称是平台实时要求。

### 双版母版

```text
目标尺寸 2010×600 px，宽高比 3.35:1。左右是两张独立设计的封面，无间隔拼接。

左侧为 1410×600 px、2.35:1 横版，占总宽度约 70.15%。主文案优先 1–2 行；左侧留白约为横版本身宽度的 8%，上下留白至少为高度的 12%。

右侧为 600×600 px、1:1 方版，占总宽度约 29.85%。对同一文案重新排字，主文案允许 2–3 行，四周留白至少为边长的 10%。色场适配方形构图。

两版各自包含完整主文案及指定的全部辅助关键词，任何文字都不跨越拼接边界。方版独立排版，不从横版机械截取。各版完整性优先于拼接处背景连续。
不绘制边框、分隔线、尺寸、比例或裁切标记。
```

### 单独横版

```text
目标尺寸 1410×600 px，宽高比 2.35:1。画面只有一张横版封面。
主文案优先 1–2 行，左侧留白约为宽度的 8%，上下留白至少为高度的 12%。
完整呈现主文案及指定的辅助关键词，全部文字只出现一次。
```

### 单独方版

```text
目标尺寸 600×600 px，宽高比 1:1。画面只有一张方版封面。
主文案允许 2–3 行，四周留白至少为边长的 10%。
完整呈现主文案及指定的辅助关键词，全部文字只出现一次。
```

## 排版适配

先确定可容纳的文字，再提交 `image_gen`。长文案优先换行，适度调整字号；用户指定的文字仍无法清楚容纳时，询问是否允许缩短，不静默删词。自主提炼的文案可在生成前继续压缩，但保留事实和含义。需要减少辅助词时，在选定文案阶段处理，横版与方版采用同一组最终文字。
